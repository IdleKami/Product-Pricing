# Idle Kami Product Pricing Studio

A UK-focused product pricing calculator for 3D printed products, engraved products, apparel, extras/components, labour, postage, VAT and profit markups.

## Features

- 3D print costing using filament, roll weight, roll cost, print time, printer wattage and electricity rate
- Extras/components calculator using pack cost, pack quantity and quantity used
- Manual labour costing using hourly wage and minutes worked
- xTool F2 / laser engraving costing using machine time, setup time, labour and risk buffer
- Apparel costing using garment code, garment cost and multiple print costs
- Optional postage included in sale price
- Optional VAT added to suggested sale prices
- Payment/platform fee estimate
- Suggested prices at 30%, 50%, 70% and custom markup
- Export/save as PDF using the browser print dialogue
- No browser storage, no tracking, no database

## How to use

Open `index.html` in a browser.

To publish on GitHub Pages:

1. Create a new GitHub repository.
2. Upload `index.html`, `styles.css`, `app.js` and this `README.md`.
3. Go to Settings → Pages.
4. Set the source to your main branch.
5. Open the GitHub Pages URL.

## Defaults

- Currency: GBP
- VAT: 20%
- Electricity: £0.2467/kWh, matching the UK average Ofgem April-June 2026 electricity unit rate
- Branding colours based on Idle Kami Design:
  - Blue: `#1f81c4`
  - Light blue: `#c5dded`
  - Off-white: `#f5f5f5`
  - Light grey: `#bcbcbc`
  - Dark grey: `#414141`
  - Charcoal: `#282828`

## Notes

This tool is for pricing estimates. Your exact energy tariff, tax situation, shipping rates, payment processor fees and business overheads may differ.
