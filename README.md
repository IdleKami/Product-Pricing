# Idle Kami Product Pricing Studio v4

Single-file static pricing app. Upload `index.html` to the root of your GitHub Pages repository.

## v4 changes
- Report summary only shows selected/active costing sections.
- Apparel, engraving, extras, postage, fees and VAT no longer appear as £0.00 blocks when not used.
- Keeps the tidy printable/PDF report layout.
