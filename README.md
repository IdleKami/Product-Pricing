# Idle Kami Product Pricing Studio

A UK-focused static web app for estimating product costs and suggested sale prices for 3D printed, engraved, apparel and component-based products.

## Deploy on GitHub Pages

Upload `index.html` and `README.md` to the root of your repo, then enable GitHub Pages from Settings > Pages > Deploy from a branch > main > /root.

## Exporting PDF

Use the app button **Export / save PDF**, then choose **Save as PDF** in your browser print dialog.
